ZIP-Level Customer Growth Prediction

T-SQL · Dynamic SQL · SSAS · SSRS · Excel · BCIT COMP 2854 coursework
Problem
Which ZIP codes will order more next year than this year? Predicting growth could help decide where to focus marketing.
My role
Built the whole pipeline on the SQLBook database: features, model, evaluation, data mart, cube, and report.
Process
Built customer-history features from earlier years with a dynamic-SQL PIVOT, trained a lookup-table model on 2013 and 2014, and tested it on 2015. Added a state-aware version of the model, loaded the predictions into a star schema (1 fact and 3 dimension tables), built an SSAS cube on it, and created an SSRS performance report.
Result
7,385 ZIP codes scored: 61.7% accuracy, 20.1% precision and 53.6% recall for growth. Only 1,089 ZIP codes actually grew, so accuracy alone was misleading, and the model flagged many false positives.
Learning
With uneven classes, precision and recall tell the real story: an always-no-growth rule would be right 85.25% of the time, so my model did not beat that baseline on accuracy. Next I would add more features and tune the model for precision.

Used Car Price Prediction

Python · Pandas · Scikit-learn · XGBoost · Team of 5
Problem
Used car prices vary widely, and buyers and sellers need fair price estimates. The data had missing values, high-cardinality fields, and outliers.
My role
Data exploration and preprocessing together with a teammate, and I presented those sections in the final class presentation.
Process
Filled missing values with an "Unknown" category, combined brand and model into one feature, and removed mileage outliers with the IQR method per model year. The team then compared Linear Regression and XGBoost with 5-fold cross-validation and tuned XGBoost with randomized and grid search.
Result
188,533 listings prepared for modeling; 4,666 mileage outliers removed (183,867 rows kept).

Layoffs: SQL Cleaning and Analysis

MySQL · CTEs · Window functions · Guided practice project
Problem
A global layoffs dataset had duplicates, inconsistent labels, text dates, and missing values, so it could not be analyzed reliably.
My role
Recreated and practiced a public tutorial project on my own in MySQL Workbench.
Process

Breast Cancer Classification

Python · Scikit-learn · SVM · Individual project
Problem
Classify tumors as malignant or benign from 30 measurements per record (569 records).
My role
Everything: exploration, scaling, modeling, tuning, and evaluation.
Process
Trained a baseline SVM, applied min-max feature scaling, then tuned hyperparameters with 5-fold cross-validated GridSearchCV (16 combinations).
Result
Feature scaling raised test accuracy from 94% to 96%. The final model scored 96% accuracy and 0.96 weighted F1 on 114 held-out records, with 100% precision and 92% recall on malignant cases.
Next step
Fit the scaler on training data only and compare against other classifiers.
